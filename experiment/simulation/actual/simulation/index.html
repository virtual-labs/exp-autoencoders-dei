Network Architecture & Data Flow

Watch how an image flows through the autoencoder network, layer by layer.

Architecture Details:

  • Input Layer (784): Flattened 28×28 pixel image
  • Encoder: Progressive compression through layers: 784 → 512 → 256 → 128 → 64 → 32 → 16 → 8 → 4 → 2
  • Latent Space (2D): Compressed representation capturing essential features
  • Decoder: Progressive reconstruction: 2 → 4 → 8 → 16 → 32 → 64 → 128 → 256 → 512 → 784
  • Output Layer (784): Reconstructed image reshaped to 28×28
  • Total Parameters: 1,071,554 trainable parameters

Understanding Latent Space:

  • Dimensionality Reduction: The autoencoder compresses 784-dimensional images into just 2 dimensions
  • Clustering: Similar items (e.g., shoes, clothing) tend to cluster together in latent space
  • Continuous Representation: Points close together represent similar visual features
  • Learning: The network learns this representation without explicit labels for features
